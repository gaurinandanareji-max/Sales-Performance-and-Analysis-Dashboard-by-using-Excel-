# Sales-Performance-and-Analysis-Dashboard-by-using-Excel-
Sales Performance and Analysis Dashboard – Excel

Project Overview

Created an interactive Excel dashboard to analyze sales performance and present business insights.

Key Activities

- Analyzed sales data using PivotTables.
- Created PivotCharts to visualize sales performance.
- Analyzed customer-wise and salesperson-wise sales.
- Identified top-performing sales values.
- Used slicers to filter dashboard reports.

Tools Used

- Microsoft Excel
- PivotTables and PivotCharts
- Slicers
- Excel Formulas
